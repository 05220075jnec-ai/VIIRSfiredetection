# Reference Notebooks

The files under `notebooks/reference/` are the original exploratory fire
detection notebooks and legacy scripts retained for methodology and report
reference.

They are not used by the automated detection pipelines. The legacy VIIRS
script remains callable through the optional manual detection API. Internal
relative paths in the notebooks reflect the exploratory workflow and may need
adjustment before rerunning individual cells.

Local pre-cleanup notebook copies are kept under `notebooks/backups/` and are
ignored by Git.
